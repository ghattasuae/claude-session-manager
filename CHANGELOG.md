# Changelog

## 0.1.0 (2026-11-08)

First public release.

- Sessions view grouped by project, with live session indicator, search and a current workspace filter.
- One-click resume in a VS Code terminal, plus fork into a new terminal.
- Rename sessions (`F2`); the name is passed to Claude with `--name`.
- Hide and unhide sessions.
- Custom terminals: save a folder and a command and reopen it with one click.
- Remember the open terminal layout per workspace and restore it after a restart.
